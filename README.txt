# adiinnovation — Professional Website

A responsive, animated one-page business website for adiinnovation.

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling and animations
- `script.js` — scroll effects, mobile navigation and WhatsApp contact form
- `assets/adiinnovation-poster.png` — supplied brand/service poster

## Run locally
Open `index.html` in a browser.

For best local testing, use a simple local server, e.g. VS Code Live Server.

## Edit
Update business text, services and contact details directly in `index.html`.
